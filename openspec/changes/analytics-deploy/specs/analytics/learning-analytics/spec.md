# analytics/learning-analytics Specification

## Purpose

为已认证学习者持久化学习记录、学习目标与成就解锁，并由 FastAPI 聚合真实统计、日历和趋势数据，替代前端 mock。

## ADDED Requirements

### Requirement: 学习记录持久化与用户隔离

系统 SHALL 允许已认证用户创建和读取自己的学习记录，记录包含主题、学习分钟数和学习日期。所有查询 MUST 按当前 access token 的 `user_id` 过滤；跨用户读取 MUST 返回 404。学习分钟数 MUST 为 1 至 1440，主题 MUST 为 1 至 120 字符，日期 MUST 为有效自然日；无效输入 MUST 返回 422 且不写库。

#### Scenario: 创建自己的学习记录
- **GIVEN** 用户已认证
- **WHEN** 用户提交有效主题、分钟数和学习日期
- **THEN** 系统保存记录并返回记录 ID 和当日聚合结果

#### Scenario: 只读取自己的记录
- **GIVEN** 用户 A 和用户 B 都有学习记录
- **WHEN** 用户 A 请求学习记录列表
- **THEN** 系统只返回用户 A 的记录

#### Scenario: 跨用户读取
- **GIVEN** 用户 A 已认证且用户 B 拥有学习记录
- **WHEN** 用户 A 请求用户 B 的记录 ID
- **THEN** 系统返回 404 且不泄露记录是否存在

#### Scenario: 无效学习记录
- **GIVEN** 用户已认证
- **WHEN** 用户提交 0 分钟、超过 1440 分钟、空主题或无效日期
- **THEN** 系统返回 422 且不保存记录

#### Scenario: 未认证写入
- **GIVEN** 请求没有有效 access token
- **WHEN** 用户尝试创建学习记录
- **THEN** 系统返回 401 且不保存记录

### Requirement: 学习目标生命周期

系统 SHALL 允许已认证用户创建、按日期列出和切换自己的学习目标。目标包含标题、分类、目标日期和完成状态；标题 MUST 为 1 至 120 字符，分类 MUST 为 1 至 60 字符，目标日期 MUST 为有效自然日。跨用户操作 MUST 返回 404；无效输入 MUST 返回 422 且不改变现有目标。

#### Scenario: 创建学习目标
- **GIVEN** 用户已认证
- **WHEN** 用户提交有效标题、分类和目标日期
- **THEN** 系统保存目标并返回待完成状态

#### Scenario: 按日期列出目标
- **GIVEN** 用户已有多个不同日期的目标
- **WHEN** 用户请求指定日期的目标列表
- **THEN** 系统只返回该日期属于当前用户的目标

#### Scenario: 切换完成状态
- **GIVEN** 用户拥有一个待完成目标
- **WHEN** 用户将目标标记为完成或恢复为待完成
- **THEN** 系统持久化新状态并返回更新后的目标

#### Scenario: 无效目标
- **GIVEN** 用户已认证
- **WHEN** 用户提交空标题、过长分类或无效日期
- **THEN** 系统返回 422 且不创建或修改目标

#### Scenario: 操作他人目标
- **GIVEN** 用户 A 已认证且用户 B 拥有目标
- **WHEN** 用户 A 尝试读取或切换用户 B 的目标
- **THEN** 系统返回 404 且不修改目标

### Requirement: 统计与趋势聚合

系统 SHALL 提供需认证的学习总览聚合，返回本周学习分钟数、已完成目标数、连续学习天数、本周目标进度和趋势点。`range=week` MUST 返回当前周每日学习分钟数，`range=month` MUST 返回最近四周的每周学习分钟数；无记录时 MUST 返回零值而不是错误。无效 range MUST 返回 422，未认证 MUST 返回 401。

#### Scenario: 周统计
- **GIVEN** 用户本周存在学习记录和已完成目标
- **WHEN** 用户请求 `range=week` 的总览
- **THEN** 系统返回四项统计和当前周每日趋势点

#### Scenario: 月统计
- **GIVEN** 用户最近四周存在学习记录
- **WHEN** 用户请求 `range=month` 的总览
- **THEN** 系统返回四项统计和最近四周的每周趋势点

#### Scenario: 没有学习数据
- **GIVEN** 用户没有任何学习记录或目标
- **WHEN** 用户请求学习总览
- **THEN** 系统返回零值统计和完整趋势骨架，不返回错误

#### Scenario: 无效统计范围
- **GIVEN** 用户已认证
- **WHEN** 用户请求不支持的 range
- **THEN** 系统返回 422 且不执行聚合查询

#### Scenario: 未认证统计
- **GIVEN** 请求没有有效 access token
- **WHEN** 用户请求学习总览
- **THEN** 系统返回 401 且不返回任何学习数据

### Requirement: 学习日历聚合

系统 SHALL 提供按月份聚合的学习日历，返回该月每一天的学习分钟数、学习记录数和完成目标数。月份 MUST 使用 `YYYY-MM` 格式并按配置时区计算；当月无记录时 MUST 返回该月日期和零值。无效月份 MUST 返回 422，其他用户的数据 MUST NOT 进入结果。

#### Scenario: 读取有记录的月份
- **GIVEN** 用户当月存在学习记录和已完成目标
- **WHEN** 用户请求该月日历
- **THEN** 系统返回覆盖整月的每日聚合结果

#### Scenario: 读取无记录的月份
- **GIVEN** 用户当月没有学习记录或完成目标
- **WHEN** 用户请求该月日历
- **THEN** 系统返回零值日期网格和明确的空状态数据

#### Scenario: 无效月份
- **GIVEN** 用户已认证
- **WHEN** 用户提交不符合 `YYYY-MM` 的月份
- **THEN** 系统返回 422 且不返回日历数据

#### Scenario: 日历用户隔离
- **GIVEN** 用户 A 和用户 B 在同一月份都有学习记录
- **WHEN** 用户 A 请求该月日历
- **THEN** 结果只包含用户 A 的聚合数据

#### Scenario: 未认证日历
- **GIVEN** 请求没有有效 access token
- **WHEN** 用户请求学习日历
- **THEN** 系统返回 401 且不返回任何日期数据

### Requirement: 成就与等级派生

系统 SHALL 返回成就目录及当前用户进度，并在达到阈值时自动解锁成就。成就 MUST 至少覆盖首次学习、连续 7 天、累计 10 小时和完成 20 个目标；重复读取 MUST NOT 重复解锁。系统 SHALL 根据学习记录计算连续学习天数和等级，并将结果同步到当前用户 Profile；客户端不得直接修改这些字段。

#### Scenario: 首次学习解锁
- **GIVEN** 用户尚未解锁首次学习成就
- **WHEN** 用户创建第一条学习记录并读取成就
- **THEN** 系统返回该成就已解锁及解锁时间

#### Scenario: 达到累计阈值
- **GIVEN** 用户累计学习时间达到 10 小时
- **WHEN** 用户读取成就目录或学习总览
- **THEN** 系统解锁累计 10 小时成就并返回进度 100%

#### Scenario: 重复读取不重复解锁
- **GIVEN** 用户已解锁某项成就
- **WHEN** 用户多次读取成就目录
- **THEN** 系统保持同一解锁记录且不产生重复成就

#### Scenario: Profile 学习字段同步
- **GIVEN** 用户新增学习记录或完成目标
- **WHEN** 系统完成聚合
- **THEN** 该用户 Profile 的连续学习天数和等级更新为派生结果

#### Scenario: 未认证成就
- **GIVEN** 请求没有有效 access token
- **WHEN** 用户请求成就目录
- **THEN** 系统返回 401 且不返回成就或 Profile 数据
